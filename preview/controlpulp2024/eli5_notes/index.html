ControlPULP：从零入门#

论文页面 · 本笔记所用 PDF · DOI

整理日期：2026-11-05。读者原创中文解读；原图归论文作者／出版方。未运行作者实验，不是独立复现。

先把四个角色放对位置#

被控负载是要完成的程序和输入，比如压缩一块日志；CPU是执行程序的硬件；控制器根据观测选运行档位；驱动／寄存器把档位落实。程序代码可以完全一样，CPU时钟变慢时每条指令对应的墙钟时间通常变长，访存或I/O等待则未必按同样比例变化。

软件控制并不意味着没有真实硬件。软件中的学习策略可控制真实CPU；也可先控制一个执行时间与能量模型。后者能验证闭环逻辑，但模型输出的J不能当真实电测。E902的RTL能在仿真中改变时钟并反馈计数；电压导致的物理功耗还需相应模型、功耗分析或板级实验。

这篇到底解决哪一件事#

用一颗管理RISC-V核加可并行的工作核集群，运行电源控制固件，并用FPGA连接模拟的多核功耗／热系统。

大规模被控CPU的观测、约束与动作数增加时，单管理核是否还能在控制期限内完成计算？如何在真实被控芯片尚未完成时验证完整控制链？

把方法想成一条流水线： OS/BMC提出性能点与功率预算 → SCMI邮箱到管理核 → 读取PVT和工作负载 → 集群计算功率分配／温控 → 电压任务与频率任务协调 → 写执行器接口 → 模拟对象产生新温度与功率 → 再采样。

先回答的问题 本文答案
输入 每处理单元的目标频率、温度、功率／活动信息，整系统预算及共享电压域约束。
输出 每核频率与各电压域电压／功率限制。
控制器 CV32E40P管理核，8核可编程集群与DMA；FreeRTOS固件。
被控对象 案例为72核HPC处理器模型，不是用户的E902，也非72核真实硅片测能。

十个先修关键词#

级别 术语／关键词 直觉、严格含义与易混点
A DVFS / DFS DVFS同时涉及动态电压与频率；只有时钟变化称DFS。电压能否改变取决于实际供电域。
A Workload 真正执行应用计算的程序与输入；本文里的控制器是另一个角色。
A Controller 根据观测选择动作的软件／硬件，可运行在同一CPU或独立控制核。
A OPP Operating Performance Point，经过允许范围验证的电压—频率组合。
A Power / Energy 功率W表示此刻消耗快慢；能量J是对时间积分。低功率不必然低能量。
B Deadline 作业必须完成的时刻；平均时延、P95与最大时延各有不同用途。
A Plant 被控对象，可是真实CPU，也可以是功耗热模型。
B MIL / HIL 模型在环／硬件在环，区别在控制器和对象哪些部分真实执行。
B PFCT / PVCT 频率与电压控制任务，周期不同且需协调。
C 可编程控制核 运行固件的CPU，与承担应用计算的被控CPU角色不同。

用一个小算例建立直觉#

500MHz下，67330周期约134.66µs；13641周期约27.28µs；在500µs周期内分别剩约73%和95%的时间。4.9倍是控制计算加速，不是被控程序加速4.9倍。

N_cycles为控制器执行周期数；f_ctrl是控制器时钟Hz，非被控CPU频率；S为剩余控制预算，秒。中断、额外通信若未包括，必须另加。

要防止的误读： 单核E902负载不需要照搬8核控制集群；控制器自身面积、能量和复杂性可能超过节能。

论文真正验证了什么#

指标 原文报告 条件／分母／边界 证据位置
主控制步 67330→13641周期，4.9× 72核控制量；不含部分共同协议开销 Table5，p24
控制周期 PFCT500µs，PVCT125µs 多速率固件任务，不是每周期完整神经网络训练 §3.1，p9–10
HIL/MIL对照 平均偏差在TDP的3%以内 9核tile、固定0.75V、2s；模拟TDP120W §5.5.1，Fig9，p25–27
面积量级 相对现代HPC die约0.1% GF22FDX综合对照；非E902板级面积／能耗 摘要、§5.1，p19

这些结果来自作者实验。算法reward、模型误差、控制器时延、被控应用速度与应用节能是不同指标，要看具体行的单位和证据。

它与你的毕设怎么接起来#

这篇最适合回答“仿真怎么闭环控制”：控制算法与被控模型交换观测和动作，按仿真时钟推进，仍然可以闭环；HIL再把控制算法放到真实硬件。你的E902可以作为被控CPU，也可以作为控制核，这两种角色不能混用。先做单核C控制器＋模型，再接寄存器和真实时钟域，最后才是板级变压验证。

最先可以尝试：P0：软件闭环与RTL闭环对齐。理由是验证算法与实现一致；最低资源是相同压缩轨迹／模型、周期与OPP；通过标准是相同输入动作顺序一致，解释所有时间偏差。

五分钟自测#

  1. 这篇输出的是下一频率、功率估计，还是通信／控制时序？
  2. 是真实负载硬件实验，还是模型／RTL／HIL？哪些部分是真的？
  3. 最重要百分比的分母和比较对象是什么？
  4. 如果换成单核E902，哪一个输入或硬件旋钮会消失？
  5. 算上采样、推理、切频和空闲时间后，节能是否还成立？
